# 03 · 3AM — The Performer

**Role:** the performer. It takes registered seams and known technique classes,
drifts the baselines, converges on a decisive test, and produces the family's
field-verified execution rows.

**Engine:** `~/.hermes/skills/security/3am-shinjitsu/scripts/exploit-intel.py`
**Dispatcher:** `route --goal "take over their session"` → 3am
**Phase:** `authentication_testing`

## axis

KNOWABLE — the documented technique classes, aimed at real seams.

3AM does not invent attacks. It matches a documented class to a registered seam,
builds the decisive test, and records whether the field result matched the
prediction.

## law

1. **Documented-PoC adaptation only.** Technique classes are canon; 3AM aims and
   compiles them. It never authors a novel weapon class, malware, or a
   destructive payload.
2. **Drift before fire.** `drift` re-checks baselines before re-probing. A stale
   baseline invalidates the proof.
3. **One decisive test.** The goal is the minimum request that proves or
   disproves the class. No shotgun spraying, no denial-of-service, no
   destructive end state.
4. **Validation-only compromise.** One proof, then stop. Do not install
   persistence, create accounts, move laterally, or retain anything of value.
5. **Negatives are results.** A blocked or non-reproducible test is registered
   as a negative and removed from the actionable queue. It is not retried until
   the environment changes.
6. **Learn only from the field.** `learn` / `promote` accept a row only after it
   has been verified against the real target; a model's opinion is not evidence.

## handoff

### Read the campaign

```bash
3am status --target <target>
3am next --target <target>
3am report --target <target>
```

### Run the loop

```bash
3am sweep --target <target> [--stack nextjs,aws,redis] \
  [--converge N] [--minproof <n>] [--budget <rounds>] \
  [--endpoint <url>] [--models <list>] [--no-drift] [--limit <n>]
```

`sweep` is the press-button loop: drift → auto-queue → converge → fire list.
It produces the ranked list; the actual confirmation still follows the family
gate and scope authority.

### Deepen a class

```bash
3am teardown '<case-or-query>' [--out <path>]
3am derive --flaw <FLAW> --seam <SEAM>
3am synthesize [--flaw <FLAW>] [--seam <SEAM>]
3am converge --candidate <id> [--confirmed-when '<predicate>'] [--facts '<facts>']
3am chain --target <target> --steps 'A→B→C' --jewel <asset> \
  --impact '<impact>' --evidence '<ref>'
3am learn --flaw <FLAW> --seam <SEAM> --probe '<probe>' \
  --confirmed-when '<predicate>' [--source '<ref>']
3am promote [--flaw <FLAW>] [--seam <SEAM>] [--apply --verified]
3am drift --target <target> [--days <n>]
```

## evidence

A 3AM row is field-verified when it carries:

- the technique class and its documented source;
- the exact request/response pair or command transcript;
- the baseline and the changed observation;
- the measurable diff;
- the timestamp and scope decision.

The row enters the dispatcher ledger through the normal evidence gate. Anything
short of that is a hypothesis, not a confirmed exploit. A takeover chain requires
every hop to exist and be ordered (`--steps`, `--jewel`, `--evidence`).

## fleet

```bash
spydermonkey.py fleet --goal "prove the strongest seam" --agents 3am
# engine brief: 3am status --target <target>
```

3AM is the fleet's execution arm. It runs only after scope and barbican
readiness are green.

## failure

| Symptom | Correct response |
|---|---|
| No actionable candidates | Run `derive` / `teardown` / `synthesize`; do not invent a class. |
| Baseline drifted | Re-baseline, then re-run the decisive test once. |
| Test blocked by WAF/403 | Register the negative, record the control, pivot to another seam. |
| Proof is not reproducible | Downgrade to hypothesis; do not `learn` or `promote` it. |
| Chain hop missing | `chain --validate` and repair the hop list; never claim a chain with a missing link. |
| Engine missing | `spydermonkey.py doctor`; do not emulate the engine with ad-hoc curl. |

A failed test that is documented is more valuable than a successful test that
cannot be reproduced.
